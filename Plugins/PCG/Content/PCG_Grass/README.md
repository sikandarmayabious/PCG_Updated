# Garden grass PCG

Use `/PCG/EdMode/DrawSplineSurface/PCG_GardenGrass_AreaTool` with Draw Spline Surface.

The Area Tool supports a weighted grass mesh array with separate material controls inside each entry, random transforms, an Excluded Actors world array, and an optional Included Surfaces world array. Inclusion is disabled by default. Actor tags are not used by this graph.

See [AREA_TOOL_GUIDE.md](AREA_TOOL_GUIDE.md) for setup, surface modes, mask precision, and plugin migration.

Material: `/PCG/EdMode/DrawSplineSurface/Grass/M_GardenGrass`.
Default mesh: `/PCG/EdMode/DrawSplineSurface/Grass/Long_grass_03`.
The older `/PCG/EdMode/Volume/PCG_GardenGrass` is retained as a legacy graph.
